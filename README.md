# 🎶 Quint Felicity – Geschlossener Mitgliederbereich

Dies ist das GitHub-Repository für den **geschlossenen Mitgliederbereich** von **Quint Felicity**.

Der Mitgliederbereich wurde im Rahmen von **TeaSpoon** entwickelt und gepflegt  
👉 https://github.com/teaspoon-de

---

## 🎤 Über Quint Felicity

**Quint Felicity** ist eine Band, die für energiegeladene Live-Auftritte, musikalische Vielseitigkeit und echte Spielfreude steht.  
Der Mitgliederbereich richtet sich ausschließlich an Bandmitglieder und dient zur Verwaltung interner Inhalte.

### Funktionen

- 📝 **Backend für den Blog** der öffentlichen Website  
- 🎵 **Verwaltung von Songs & Setlists**  
- 📅 **Verwaltung von Terminen**  
- 🔒 Geschlossener Zugang nur für Bandmitglieder

---

## 🌐 Über diesen Bereich

Der Mitgliederbereich wurde entwickelt, um Bandmitglieder effizient zu unterstützen und die Organisation zu erleichtern.

**Schwerpunkte:**

- 🔧 Funktionales, auf die Band zugeschnittenes Backend  
- 📂 Strukturierte Verwaltung von Songs, Setlists und Terminen  
- 🖥 Browserbasiert & responsiv  
- 🔒 Sicherheit und Zugriffskontrolle für Mitglieder  

---

## 📁 Projektstruktur

```text
/
├─ src/                    # Backend-Quellcode (PHP, JS, etc.)
├─ public/                 # Frontend für eingeloggte Mitglieder
├─ docker/                 # Docker-Konfiguration für Dev & Deployment
├─ docker-compose.yaml     # Prod Setup
├─ docker-compose.dev.yaml # Dev Setup
├─ .gitignore
├─ README.md
└─ weitere Konfigurationsdateien
```

---

## 🚀 Deployment

Der Mitgliederbereich ist für containerbasiertes Deployment ausgelegt:

- Docker & Docker Compose  
- NGINX oder Apache als Webserver  
- Automatische SSL-Zertifikate über zentrale Umgebung

Zugehörige Globale Docker-Umgebung:  
https://github.com/teaspoon-de/global-docker-setup
